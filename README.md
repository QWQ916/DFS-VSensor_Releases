# Приложение для визиографа DFS-VSensor
<b>DFS-VSensor</b> — программа для работы с интраоральными рентген-датчиками и камерами в стоматологии. Создана как замена штатному ПО производителя: быстрее, удобнее, с общей базой пациентов и снимков на PostgreSQL для нескольких рабочих мест в клинике.
Бесплатная версия и платные тарифы. Обновления устанавливаются автоматически: приложение проверяет последний релиз в этом репозитории, сверяет подпись и заменяет файлы.

В данном репозитории собраны релизы с версионированием, именно отсюда приложение берёт новые версии и устанавливает их в систему клиента. Это позволяет удаленно скачивать новые версии в оффлайн-приложение и быть в актуальной версии всегда, позволяя динамично и с обратной связью добавлять функционал и устранять недочёты в самом приложении.

### Стек: C#, .NET, PostgreSQL, GitHub API.
