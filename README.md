# DFS-VSensor_Releases
В данном репозитории собраны релизы с версионированием, чтобы пользователи новые версии скачивали отсюда через приложение. Это позволяет удаленно скачивать новые версии в оффлайн-приложение и быть в акутальной версии всегда.
